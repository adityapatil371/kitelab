How to read this table

Each row is one trading rule: a mechanical instruction like “buy after a stock has fallen to a 20-day low”, run over about a thousand Indian stocks with one pot of money, with real trading costs charged. The same rule appears twice, once for each way of deciding when to sell.

The only question worth asking is the last column but one: did the rule beat simply buying every stock and waiting? That is what “buy & hold” means, and it is the honest thing to compare against, because it takes no skill and almost no effort. A negative number there means the rule lost to doing nothing.

Five checks is five ticks or crosses in a row, one for each test a rule must pass before this page will call it real. All five have to pass. Click any row to see what each check asked and why it failed.

Worst fall is the deepest drop from a high point to the low that followed it — the part of the record you would have had to sit through. Two rules that end up in the same place are not the same rule if one of them halved on the way.

How every column is calculated

Rules that pass all five checks are listed first; within each group the order is by return against the worst fall it took to earn it. A rule that fails even one check ranks below every rule that passes all five, whatever its other numbers say. Click a column heading to sort by it instead. A row reading no trades is not a gap in the data: the build worked that cell out and the account could not act on it — nothing affordable, or nothing the rule pointed at in that span.

The rest of the numbers did not go away. This table was cut to five columns on 2026-09-19 because fourteen columns is a spreadsheet, not an answer. Growth a year, ending money, the number of trades, how much of the money was actually working, the luck tests and the year-by-year record are all on the Detail view, one rule at a time, each with a sentence saying what it means. Click any row to get there.
